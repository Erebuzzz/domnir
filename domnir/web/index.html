    Dómnir Trust Boundaries & Architecture

    Vultr Agent Rush Hackathon, Challenge 01: Blast Radius Zero

    01
    Host Never Runs Untrusted Code

    AI-generated flight controllers are restricted to an isolated Microsandbox microVM or an isolated subprocess. The host simulation harness is separate.

    02
    Secret Hygiene

    No Vultr Serverless Inference API keys, database credentials, or host secrets are ever passed into the guest execution cage or the frontend.

    03
    Host-Owned MuJoCo Simulation

    Only the trusted harness (Forseti) advances simulation physics, applies actuator bounds, and records truth telemetry. The guest only receives sensor observations.

    04
    Deterministic Replay Verification

    Recorded action vectors are replayed on a pristine MuJoCo instance to prove bit-for-bit physical trajectory reproducibility (<= 1e-12 m difference).

    05
    Ephemeral Teardown Guarantee

    Every sandbox is subject to strict CPU, memory, and wall-clock deadlines. Cleanup and lease termination are enforced on normal and error paths.

    06
    Truth in Qualification

    Finite falsification campaigns identify boundary counterexamples. They are never represented as mathematical safety proofs or real-world airworthiness.
